# Fabriq Books does the legwork. Your team makes the calls.

**Today**

1. Controller opens aging report → exported from QBO into spreadsheet
2. Manually cross-references bank lines → one by one, tab by tab
3. Enters matches back into QBO → risk of errors on re-entry
4. Repeats next month → same work, every cycle

**3–5 hours/month per account**

# With Fabriq Books

1. "Clear October bank account" → controller states the goal
2. Fabriq Books does the analysis → finds matches across all sources
3. Proposes matches for sign-off → approve, reject, or edit each one
4. Applies confirmed matches → nothing touches the books without approval

**Review takes minutes, not hours**

Your ERP stays. QuickBooks · Xero · Zoho Books
