# The problem

<v-clicks>

- **SMB finance is stuck between two bad options:** static ledgers (QuickBooks, Xero) that won’t bend to *your* matching rules and approval chains, or expensive one-off builds.
- **Today's tools don't learn:** workflows are learnable - e.g. “amount + date window = likely match” - but today’s tools don’t learn from your data and feedback.
- **Cost:** tens of hours a month on manual reconciliation — and teams still can’t optimize the process because the stack won’t adapt.

</v-clicks>

---
layout: default
---

# Value proposition

<v-clicks>

- **Agents run the mechanical work:**  matching, categorizing, triaging - so finance spends time on **judgment**, not grunt work.
- **Same agents, many workflows:** reconciliation, payables, collections, or other flows you define — **not** a single vertical silo.
- **Agents that improve:** as the business changes.

</v-clicks>

---
layout: default
---

# Underlying magic

<v-clicks>

- **Metadata-driven core:** define financial data and workflows once; generate APIs, UI, and permissions from schema — **less custom code**.
- **Agent loop:** plan → execute on live data → **suggest** matches → **learn** from approvals/rejections → **adapt** when patterns shift.
- **Human-in-the-loop by design:** high-confidence paths can auto-execute; **everything else** queues for review

</v-clicks>

# Business model

<v-clicks>

- **Usage / outcome-aligned pricing:** e.g. per reconciled transaction, per automated account, or active automation months.
- **Example structure:** ~$500/mo base + small per-transaction fee — scales with **value**, not seat count alone.
- **Why:** aligns Fabriq with customers who **automate more**

</v-clicks>

# Go-to-market

<v-clicks>

- **Phase 1 (0–6 mo):** 2–3 **paying pilots**, reconciliation-first — measurable ROI, case studies.
- **Phase 2 (6–12 mo):** productize reconciliation; **1–2 adjacent verticals**.
- **Phase 3 (yr 2):** payables, AR, multi-account flows → **20–50** paying customers.
- **Channels:** direct (content, LinkedIn); **accounting firm** partners; **vertical** platforms (staffing, e-com).

</v-clicks>

# Competition

| | **Incumbents** | **Fabriq** |
|---|----------------|------------|
| **QuickBooks / Xero** | Great ledgers, **limited** adaptive automation | **Agent layer** that learns your workflow |
| **NetSuite / SAP** | Powerful, **$100K+** and long cycles | **SMB/mid-market** speed + configurability |
| **Ramp / Rillet / Kick** | Strong **vertical** agentic plays | **Horizontal** — recon, AP, collections, **your** rules |
| **Custom dev** | Fits once, **hard to evolve** | **Product + learning loop** |

 **We don’t replace** QuickBooks — we’re the **autonomous layer** that makes financial workflows **adaptable without a dev shop**.
