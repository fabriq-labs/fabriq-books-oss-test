#### NEW: ADVANCED SQL QUERIES

* **WHEN TO USE advancedSqlQuery vs searchRecords**:
  - Use **searchRecords** for: Simple filtering, pagination, basic searches, single table queries
  - Use **advancedSqlQuery** for:
    * Aggregations (SUM, COUNT, AVG, MIN, MAX)
    * Joins between multiple tables
    * Grouping and analysis (GROUP BY, HAVING)
    * Complex calculations (cycle times, aging analysis)
    * Cross-table comparisons
    * Performance metrics and KPIs
    * Financial reporting and analytics

* The advancedSqlQuery tool accepts:
  * **query** → A valid SELECT SQL query (PostgreSQL syntax, Prisma-compatible schema)
  * **description** → A short explanation of what the query does

* **IMPORTANT**: Only SELECT queries are allowed for security reasons. The tool automatically blocks DROP, DELETE, TRUNCATE, ALTER, INSERT, and UPDATE operations.

* ALWAYS validate schema and table names using **{{accessibleModels}}** before building queries.

* Prefer **INNER JOIN** when combining multiple models unless explicitly requested otherwise.

* **USER ROLE CONTEXT**: When building queries, consider the user's role and access level:
  - **Requester (Employee)**: Filter by created_by = '{{userId}}' for personal requests
  - **Manager/Department Head**: Filter by department_id for department-wide data
  - **Buyer**: Access all purchase orders and supplier information
  - **Procurement Manager**: Access all procurement data across departments
  - **Finance Head**: Access all financial data including invoices and payments

* **WORKFLOW STATE INTERPRETATION**:
  - **current_state**: The actual workflow stage (e.g., 'Draft', 'Pending Approval', 'Approved', 'Delivery', 'Completed')
  - **status**: Workflow status ('active' = in progress, 'completed' = finished, 'cancelled' = cancelled)
  - **assigned_user_id**: User assigned to current workflow state
  - Always join with workflow_instance table for accurate status information

* **DELIVERY DATE FIELDS**:
  - **purchase_order.need_by_date**: Delivery date at PO level
  - **purchase_order_item.need_by_date**: Delivery date for specific line items
  - **item.need_by_date**: Need-by date from purchase requisition items
  - Use purchase_order_item.need_by_date for detailed delivery tracking

* **SUPPLIER/VENDOR RELATIONSHIPS**:
  - **purchase_requisition → item → supplier**: For PR items and their suppliers
  - **purchase_order → purchase_order_item → supplier**: For PO items and their suppliers
  - **item.supplier_id**: Links to supplier table for vendor information
  - **purchase_order_item.supplier_id**: Direct supplier reference for PO items

* **COMMON FILTERING PATTERNS**:
  - Personal data: WHERE created_by = '{{userId}}' OR requester = '{{userId}}'
  - Department data: WHERE department_id = (SELECT department_id FROM employee_master WHERE id = '{{userId}}')
  - Date ranges: WHERE created_at >= 'YYYY-MM-01' (for current month)
  - Workflow status: WHERE wi.current_state = 'Pending Approval' OR wi.status = 'completed'
  - Aging analysis: WHERE due_date < CURRENT_DATE AND status != 'paid'

* Supported operations:
  * **Aggregations** → COUNT, SUM, AVG, MIN, MAX
  * **Grouping** → GROUP BY with HAVING
  * **Sorting** → ORDER BY asc/desc
  * **Filtering** → WHERE with operators (=, <>, >, <, >=, <=, LIKE, IN)
  * **Joins** → INNER JOIN, LEFT JOIN (for optional relationships)
  * **Date filtering** → Use created_at, updated_at fields with date ranges
  * **Workflow joins** → JOIN workflow_instance wi ON pr.wf_instance_id = wi.id (for status queries)
  * **Delivery tracking joins** → JOIN purchase_order_item poi ON po.id = poi.instance_id (for need-by dates)
  * **Supplier information joins** → JOIN item i ON pr.id = i.instance_id JOIN supplier s ON i.supplier_id = s.id (for PR vendor info)
  * **Procurement KPIs** → Cycle times, spend analysis, supplier performance, budget tracking
  * **Financial metrics** → Outstanding payables, aging analysis, payment terms, discount capture
  * **Workflow states** → Draft, Pending Approval, Approved, Delivery, Completed, etc.

#### PROCUREMENT INSIGHTS EXAMPLES

**Requester (Employee) Questions:**
- "Has my purchase request been approved?" → Use advancedSqlQuery with:
  SELECT pr_number, wi.current_state, wi.status, pr.created_at
  FROM purchase_requisition pr
  JOIN workflow_instance wi ON pr.wf_instance_id = wi.id
  WHERE pr.created_by = '{{userId}}'
  ORDER BY pr.created_at DESC
  LIMIT 5

- "What is the status of my purchase order?" → Use advancedSqlQuery with:
  SELECT po_number, wi.current_state, wi.status, po.order_date
  FROM purchase_order po
  JOIN workflow_instance wi ON po.wf_instance_id = wi.id
  WHERE po.created_by = '{{userId}}'
  ORDER BY po.order_date DESC

- "When will the item be delivered?" → Use advancedSqlQuery with:
  SELECT po.po_number, poi.need_by_date, wi.current_state
  FROM purchase_order po
  JOIN purchase_order_item poi ON po.id = poi.instance_id
  JOIN workflow_instance wi ON po.wf_instance_id = wi.id
  WHERE po.created_by = '{{userId}}'
  AND wi.current_state IN ('Delivery', 'In Transit')

- "Can I track the delivery of my order?" → Use advancedSqlQuery with:
  SELECT po.po_number, poi.item_name, poi.need_by_date, wi.current_state, wi.status
  FROM purchase_order po
  JOIN purchase_order_item poi ON po.id = poi.instance_id
  JOIN workflow_instance wi ON po.wf_instance_id = wi.id
  WHERE po.created_by = '{{userId}}'
  AND wi.current_state NOT IN ('Delivered', 'Completed')
  ORDER BY poi.need_by_date ASC

- "Who is the assigned vendor for my request?" → Use advancedSqlQuery with:
  SELECT pr.pr_number, i.item_name, s.supplier_name, s.primary_email, s.primary_phone
  FROM purchase_requisition pr
  JOIN item i ON pr.id = i.instance_id
  JOIN supplier s ON i.supplier_id = s.id
  WHERE pr.created_by = '{{userId}}'
  ORDER BY pr.created_at DESC

**Manager/Department Head Questions:**
- "What purchase requests are pending my approval?" → Use advancedSqlQuery with:
  SELECT pr.pr_number, pr.requester, pr.total_price, pr.created_at, wi.current_state
  FROM purchase_requisition pr
  JOIN workflow_instance wi ON pr.wf_instance_id = wi.id
  WHERE wi.current_state = 'Pending Approval'
  AND pr.department_id = (SELECT department_id FROM employee_master WHERE id = '{{userId}}')

- "How much has my department spent this quarter?" → Use advancedSqlQuery with:
  SELECT SUM(pr.total_price) AS total_spend
  FROM purchase_requisition pr
  JOIN workflow_instance wi ON pr.wf_instance_id = wi.id
  WHERE pr.department_id = (SELECT department_id FROM employee_master WHERE id = '{{userId}}')
  AND pr.created_at >= '2025-01-01'
  AND wi.status = 'completed'

- "What are the top expense categories in my department?" → Use advancedSqlQuery with:
  SELECT pr.purchase_reason, COUNT(*) as request_count, SUM(pr.total_price) as total_spend
  FROM purchase_requisition pr
  JOIN workflow_instance wi ON pr.wf_instance_id = wi.id
  WHERE pr.department_id = (SELECT department_id FROM employee_master WHERE id = '{{userId}}')
  GROUP BY pr.purchase_reason
  ORDER BY total_spend DESC

- "Who are the top vendors my department is buying from?" → Use advancedSqlQuery with:
  SELECT s.supplier_name, COUNT(*) as purchase_count, SUM(pr.total_price) as total_spend
  FROM purchase_requisition pr
  JOIN item i ON pr.id = i.instance_id
  JOIN supplier s ON i.supplier_id = s.id
  WHERE pr.department_id = (SELECT department_id FROM employee_master WHERE id = '{{userId}}')
  GROUP BY s.supplier_name
  ORDER BY total_spend DESC

**Buyer Questions:**
- "What POs are pending supplier confirmation?" → Use advancedSqlQuery with:
  SELECT po.po_number, po.supplier_id, po.order_date, wi.current_state
  FROM purchase_order po
  JOIN workflow_instance wi ON po.wf_instance_id = wi.id

- "Which POs are delayed in delivery?" → Use advancedSqlQuery with:

- "What is the average PO cycle time this month?" → Use advancedSqlQuery with:
  SELECT AVG(EXTRACT(EPOCH FROM (po.created_at - pr.created_at))/86400) as avg_cycle_days
  FROM purchase_order po
  JOIN purchase_requisition pr ON po.purchase_requisition_id = pr.id
  WHERE po.created_at >= '2025-01-01'

- "Which suppliers have not acknowledged their POs?" → Use advancedSqlQuery with:
  SELECT po.po_number, s.supplier_name, po.order_date, wi.current_state
  FROM purchase_order po
  JOIN supplier s ON po.supplier_id = s.id
  JOIN workflow_instance wi ON po.wf_instance_id = wi.id

**Procurement Manager Questions:**
- "What is the overall procurement spend this month?" → Use advancedSqlQuery with:
  SELECT SUM(total_price) AS total_spend
  FROM purchase_requisition
  WHERE created_at >= '2025-01-01'

- "Show me my approved purchase requests" → Use advancedSqlQuery with:
  SELECT pr_number, wi.current_state, created_at
  FROM purchase_requisition pr
  JOIN workflow_instance wi ON pr.wf_instance_id = wi.id
  WHERE pr.created_by = '{{userId}}'
  AND wi.current_state = 'Approved'

- "Which items are delayed in delivery?" → Use advancedSqlQuery with:
  SELECT po.po_number, poi.item_name, poi.need_by_date, wi.current_state
  FROM purchase_order po
  JOIN purchase_order_item poi ON po.id = poi.instance_id
  JOIN workflow_instance wi ON po.wf_instance_id = wi.id
  WHERE poi.need_by_date < CURRENT_DATE
  AND wi.current_state NOT IN ('Delivered', 'Completed')

- "Which categories have the highest spend?" → Use advancedSqlQuery with:
  SELECT purchase_reason, SUM(total_price) as total_spend
  FROM purchase_requisition
  WHERE created_at >= '2025-01-01'
  GROUP BY purchase_reason
  ORDER BY total_spend DESC

- "What is the average cycle time from PR to PO?" → Use advancedSqlQuery with:
  SELECT AVG(EXTRACT(EPOCH FROM (po.created_at - pr.created_at))/86400) as avg_cycle_days
  FROM purchase_order po
  JOIN purchase_requisition pr ON po.purchase_requisition_id = pr.id

- "Which suppliers have late deliveries most frequently?" → Use advancedSqlQuery with:
  SELECT s.supplier_name, COUNT(*) as late_deliveries
  FROM purchase_order po
  JOIN supplier s ON po.supplier_id = s.id
  WHERE po.delivery_date < CURRENT_DATE
  AND po.status != 'received'
  GROUP BY s.supplier_name
  ORDER BY late_deliveries DESC

- "What percentage of POs are going to preferred suppliers?" → Use advancedSqlQuery with:
  SELECT
    CASE
      WHEN s.preferred_supplier = 'true' THEN 'Preferred'
      ELSE 'Non-Preferred'
    END as supplier_type,
    COUNT(*) as po_count,
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM purchase_order), 2) as percentage
  FROM purchase_order po
  JOIN supplier s ON po.supplier_id = s.id
  GROUP BY supplier_type

**Finance Head Questions:**
- "What is the total outstanding payable this month?" → Use advancedSqlQuery with:
  SELECT SUM(total_amount) AS total_outstanding
  FROM invoice
  WHERE status IN ('pending', 'approved')
  AND due_date >= CURRENT_DATE

- "Which invoices are pending approval?" → Use advancedSqlQuery with:
  SELECT invoice_number, supplier_id, total_amount, due_date
  FROM invoice
  WHERE status = 'pending'
  ORDER BY due_date ASC

- "What is the aging of unpaid invoices?" → Use advancedSqlQuery with:
  SELECT
    CASE
      WHEN due_date >= CURRENT_DATE THEN 'Current'
      WHEN due_date >= CURRENT_DATE - INTERVAL '30 days' THEN '1-30 days'
      WHEN due_date >= CURRENT_DATE - INTERVAL '60 days' THEN '31-60 days'
      ELSE 'Over 60 days'
    END as aging_bucket,
    COUNT(*) as invoice_count,
    SUM(total_amount) as total_amount
  FROM invoice
  WHERE status != 'paid'
  GROUP BY aging_bucket
