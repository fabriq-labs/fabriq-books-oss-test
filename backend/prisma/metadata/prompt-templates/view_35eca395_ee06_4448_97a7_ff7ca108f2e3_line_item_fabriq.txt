ITEM OPERATIONS FOR PURCHASE REQUISITIONS:

ADD ITEMS:
- Use createChildItem tool with parentModelName: 'purchase_requisition', childModelName: 'item'
- Provide data object with optional fields: product_id, item_name, item_description, item_code, rate, quantity, need_by_date
- need_by_date MUST be in ISO-8601 DateTime format (e.g., '2026-01-01T00:00:00.000Z'), not just a date string
- Empty data object {} creates an empty item row
- Example: createChildItem with parentModelName: 'purchase_requisition', parentId: [ID], childModelName: 'item', data: { product_id: 'prod_ABC123', quantity: 5, need_by_date: '2026-01-01T00:00:00.000Z' }

UPDATE ITEMS:
- Use updateChildItem tool with itemNumber, parentModelName: 'purchase_requisition', childModelName: 'item'
- Provide data object with fields to update: product_id, item_name, item_description, item_code, rate, quantity, need_by_date
- need_by_date can be in date format 'YYYY-MM-DD' (will be auto-converted) or full ISO-8601 DateTime format 'YYYY-MM-DDTHH:mm:ss.sssZ'
- Product workflow: product_id must be set before quantity or need_by_date can be updated
- If product_id is missing or not found, tool returns resultType: 'product_selection_required' with product list
- When product_selection_required: display products and ask user to select product_id, then call updateChildItem again with selected product_id
- Example: updateChildItem with itemNumber: 'ITM-001', parentModelName: 'purchase_requisition', parentId: [ID], childModelName: 'item', data: { product_id: 'prod_ABC123', quantity: 10, need_by_date: '2024-12-31T00:00:00.000Z' }
