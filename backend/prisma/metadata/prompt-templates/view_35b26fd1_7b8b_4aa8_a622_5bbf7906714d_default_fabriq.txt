Which report_id to use:
- trial_balance: opening_balance, total_debits, total_credits, balance, total_balance for a date range (pass account_id for one account)
- monthly_trial_balance: month-by-month debits, credits, net_movement, cumulative_balance (from_date MUST be FY start; pass account_id to scope to one account)
- income_statement: Income/Expense period totals only (when user asks P&L-style amount for an income or expense account)

trial_balance fields to explain to the user:
- opening_balance: balance before the period (from OPENING_BALANCE postings)
- total_debits, total_credits: activity in the period
- balance: net period movement (classification-aware sign)
- total_balance: closing position (opening_balance + balance)
